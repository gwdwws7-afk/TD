# Milestone: M2 20-Level Campaign

> **Status**: Planned  
> **Target Window**: 2026-06-07 ~ 2026-08-29  
> **Owner**: user + codex  
> **Source Plan**: `design/gdd/full-project-plan-emberline-defense-v2.0.md`

## Goal
在 M1 垂直切片基础上，完成可发布战役主体：20关内容、全塔可升级、共振战斗系统可玩可调。

## Success Criteria
1. 20关全部可进入、可通关或失败结算。
2. 所有可建造塔均支持 3 阶升级与 2 分支选择。
3. 共振战斗系统（窗口 + 命令）可稳定运行并可读。
4. 每关能输出关键统计（到达波次、失败标签、基础战斗数据）。
5. 章节难度曲线符合目标区间，失败原因可解释。

## Scope
### In
- 关卡 1-20 的波次与敌人编排
- 全塔升级规则统一化
- 记忆点战斗系统（共振）
- 统计与平衡闭环

### Out
- 联机模式
- 无尽模式
- 大体量剧情演出

## Exit Checklist
- [ ] 20关内容冻结
- [ ] 全塔升级完成并验证
- [ ] 共振系统完成并通过体验验收
- [ ] 关键平衡指标达标
- [ ] 无 S1/S2 阻断问题
