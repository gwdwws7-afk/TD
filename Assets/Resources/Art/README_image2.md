## Generate with script

From project root:

```powershell
.\tools\generate_td_art.ps1
```

Dry run (no API call):

```powershell
.\tools\generate_td_art.ps1 -DryRun
```

## Notes

- Requires `OPENAI_API_KEY` for live generation.
- If `OPENAI_API_KEY` is unavailable, run `python .\tools\generate_td_frame_art.py` to generate a complete local HD non-pixel-art fallback set (static + animated).
- The importer at `Assets/Editor/TDArtImporter.cs` auto-imports these files as Unity sprites.
- Runtime will still work without generated art, using fallback sprites from code.
