# P13.0 Player Trust and Result Integrity

## Goal

Make the run result trustworthy before further balance or presentation work:

- Score only systems the player can currently use.
- Keep tactical grade aligned with survival quality.
- Recommend changes at the route segment that actually failed.
- Prevent combat feedback layers from appearing above modal result surfaces.
- Gate all P12.4 player runs on these rules.

## Rating Rules

The five tactical dimensions remain Coverage, Counter, Output, Economy, and Command.

- Coverage weights overall clear at 35%, weakest-lane clear at 20%, and integrity retention at 45%.
- Counter ignores threat categories for which no currently unlocked tower is a valid counter.
- Command receives a neutral 100 while resonance is not unlocked.
- A completed defeat cannot score above 59 / D.
- A victory below 25% survival quality cannot score above 69 / C.
- A victory below 50% survival quality cannot score above 79 / B.
- A victory below 80% survival quality cannot score above 89 / A.
- Survival quality uses the lower of final integrity retention and retention after cumulative integrity damage, so healing cannot erase all leak pressure.

## Recommendation Rules

- Select a segment with escapes or unresolved enemies before considering raw route heat.
- If no segment failed, inspect the weakest covered active segment.
- Never say "add coverage" when a segment has zero leak/live pressure.
- A clean segment at 90+ coverage explicitly says coverage is sufficient.
- Counter suggestions include only tower kinds unlocked for the current mission.
- Preserve the operational third recommendation for scenario, command, matrix, or low-value tower correction.

## Modal Layer Rules

When the mission board, formation panel, profile, settings, or run result is modal:

- Stop accepting new floating combat feedback.
- Stop accepting new combat cinematics.
- Destroy active floating signals.
- Hide the signal and cinematic roots.
- Hide playback controls and the tactical feed.

The presentation layer becomes available again only after the modal closes.

## Automation Gate

`DebugAuditP130ForTest` verifies:

- Perfect, strained, critical, strong, and defeat grade boundaries.
- Clean-route and failed-route recommendation wording.
- Exactly three current recommendations with no zero-leak/add-coverage contradiction.
- Tactical feed, floating signals, and cinematics suppressed under the result modal.

P12.4 MCP runs now require `p130Audit=True`. The 20-clear wrapper also includes this value in `surfacePass`.
