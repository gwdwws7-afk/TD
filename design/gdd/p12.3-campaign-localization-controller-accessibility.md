# P12.3 Campaign, Localization, Controller and Accessibility

## Shipping intent

P12.3 turns the campaign and presentation controls into player-facing release surfaces. The campaign map must read as an authored rail-front operation, not a 20-cell debug table. Chinese and English must share the same layout contract, input focus and save-backed settings.

## Campaign surface

- Four persistent chapter tabs show the campaign's large-scale route.
- Only the selected chapter's five missions are visible on the rail at one time.
- Each chapter follows Introduce -> Practice -> Reinforce -> Synthesis -> Exam.
- The selected mission owns the right-side intelligence column: scope, threats, contract, counter plan and record.
- Chapter mastery and the permanent chapter reward remain visible without opening the profile archive.
- Formation and profile management remain one action away, but no longer compete with all 20 mission nodes.

## Localization and fonts

- `TDLocalization` owns the persisted `English` / `SimplifiedChinese` language choice.
- Every runtime `Text` stores its English source string so switching language is reversible without rebuilding the scene.
- English uses Barlow Semi Condensed.
- Simplified Chinese ships with Noto Sans CJK SC Regular under the SIL Open Font License; Windows system fonts are fallback only.
- Dynamic campaign, enemy, tower, mechanic, HUD and tutorial terms pass through the same localization layer.

## Settings and accessibility

- Settings are available from the HUD and pause the battle without stealing an existing player pause state.
- Persisted controls: language, UI scale, large text, color-independent markers, subtitles, sound captions, master volume, music volume and effects volume.
- Sound captions control the tactical event strip; subtitles control cinematic body copy.
- Low-resolution play gets an additional scale assist and responds to resolution changes while the scene is running.
- Tutorial start, step completion, completion, skip and drop-off are recorded per profile slot.

## Controller and keyboard

- Every runtime `Button` and `Slider` has automatic navigation and a color-independent four-rail focus frame.
- The runtime `InputSystemUIInputModule` explicitly assigns move, submit and cancel actions.
- Gamepad: A confirm, B back, Y start wave, X scenario command, shoulders change speed and Start opens settings.
- Six keyboard actions can be rebound and persist through PlayerPrefs.

## Release gate

Run:

```powershell
./tools/td_mcp_p123_localization_accessibility_matrix.ps1
```

The gate covers campaign, formation, profile and settings surfaces at 960x540 and 1920x1080 in both languages. Every run must pass bounds, overlap, text fit, console, focus coverage, bundled font and P12.3 audit checks.

Latest verified matrix: `output/playtest/p123_matrix/p123_matrix_index.json` with 16/16 passing runs.
