# P13.2 Formal UI Art Production

## Shipping intent

P13.2 replaces the remaining programmer-facing presentation with an authored
Emberline interface system. Every major surface shares the same forged rail,
blackened steel, enamel and signal-light vocabulary while retaining a distinct
composition and immediate functional identity.

The release standard is:

- no flat placeholder blocks;
- no code-drawn decorative borders;
- no generic panel reused without a surface identity;
- no unresolved text overflow at 960x540 or 1920x1080;
- no English result terminology inside the Chinese L20 completion flow.

## Authored asset set

Runtime atlases:

- `Assets/Resources/Art/UI/P13/surface_identity_atlas_v2.png`
- `Assets/Resources/Art/UI/P13/hud_icon_atlas_v2.png`

Source-preserving transparent variants remain beside the runtime atlases. Chroma
source captures are stored outside `Resources` under
`output/imagegen/p13.2/`, so they cannot enter a player build.

The surface atlas is a 3x3 authored identity set:

1. battle HUD;
2. wave intelligence;
3. tower upgrade;
4. interactive tutorial;
5. campaign command;
6. prebattle formation;
7. campaign archive;
8. settings and accessibility;
9. run result.

The icon atlas is a 5x5, 25-symbol gameplay set:

- wave, integrity, budget, enemy and build;
- armor and four resistance families;
- armor break, slow, exposed, resonance and stagger;
- Ember, Fracture, route switch, purge and boss break commands;
- rating, damage, kills, hotspot and gamepad.

Atlas sprites are cropped at runtime on exact grid boundaries. The enhanced
`v2` atlases increase local contrast and edge clarity for 24-30 px HUD use.
No generated source image or API credential is embedded in project code.

## Surface compositions

### Battle HUD

The top rail is the persistent command instrument. Wave, integrity and budget
now use semantic medallions, fixed metric cells and authored nine-slice chrome.
Start wave, scenario commands, resonance commands and the tower build bar use
the same command language without competing with the map.

### Wave preview

Wave intelligence is a right-side threat docket with wave identity, enemy
composition, weakness and route information. It is visually related to the HUD
but uses a dedicated signal accent and compact rail header.

### Tower upgrade

The upgrade surface owns branch, damage and resonance iconography. At 960p,
the summary is reduced to two stat lines and the branch decision remains the
dominant action.

### Tutorial

The tutorial is a centered field directive with a dedicated objective marker,
step progress, confirm and skip actions. Compact HUD panels no longer receive
large decorative watermarks, preventing false interaction targets.

### Campaign

The campaign board uses a rail-command crest and reserves its right column for
selected-mission intelligence. At 960p, redundant contract, scope and mastery
copy is removed while mission state, threat and deployment remain visible.

### Formation

Formation uses a squad-network identity and preserves tower role, doctrine,
counter coverage and deployment as its primary hierarchy.

### Archive

The player profile and full-campaign result use an archive seal, record-ledger
composition and explicit save/profile hierarchy. The complete Chinese campaign
result now uses a dedicated Chinese template rather than substring replacement.

### Settings

Settings use a control-instrument crest and dedicated gamepad symbol. Language,
UI scale, text size, color-independent markers, captions and audio controls keep
their existing input and persistence behavior.

### Run result

The result surface is a report board, not a text dump:

- five score axes render as colored bars with semantic icons;
- route control and tower contribution render as comparative bars;
- the top three road heat segments use hotspot identity;
- failure causes, economy recap and three recommendations remain separate
  information bands.

## Frame and style enforcement

`TDUiWorldSkin` applies authored bitmap and nine-slice frames, then delegates
surface identity to `TDUiP132Art`. The P13.2 audit verifies both atlases and
requires every eligible visible surface to have its authored identity rail.
Large panels additionally require a surface medallion.

The existing world-skin audit continues to reject:

- legacy IMGUI chrome;
- raw decorative images;
- missing panel sprites;
- unskinned buttons;
- missing bundled fonts.

## Localization corrections

L20 victory now renders `精通 3/3` instead of `MASTERY 3/3`.

The full campaign completion state now has explicit English and Simplified
Chinese templates for:

- title, operation summary and campaign mastery;
- chapter mastery and campaign record;
- long-term rewards and archive status;
- completion recap and next objective;
- `战役完成` and `战役档案` actions.

This also removes the previous replacement-order bug that translated the `ARC`
inside `Campaign Archive`.

The campaign-completion test fixture now applies final rewards in the same
runtime order as a real completed campaign, restoring a trustworthy difficulty
runtime audit.
