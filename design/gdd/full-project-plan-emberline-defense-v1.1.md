## 1. 项目摘要
《Emberline Defense》是一款 2D 塔防策略游戏，核心卖点是“波次语法 + 反制链 + 失败可读性”。  
玩家通过有限金币进行布防与升级，持续应对不同敌群压力。每一波都承担明确教学或考试目标，失败后系统给出可执行原因标签，支持快速重开与策略迭代。

## 2. 产品定位
### 2.1 品类定位
- 类型：2D Tower Defense（单机）
- 视角：俯视 2D
- 核心体验：高密度决策、阵型构筑、压力下资源分配

### 2.2 目标用户
- Primary：策略向、数值向玩家（Achiever / Strategist）
- Secondary：喜欢尝试组合与优化路径的探索型玩家
- 非目标用户：偏纯挂机、低决策、弱反馈需求的玩家

### 2.3 平台与发售策略
- 首发平台：PC（Windows）
- 次级平台：Web（轻量版本验证传播）
- 发售形态：单机买断优先；后续可评估 DLC 或内容包

## 3. 愿景与设计原则
### 3.1 愿景
打造“可学习、可解释、可复盘”的塔防：玩家输得明白，赢得聪明。

### 3.2 设计支柱（Pillars）
1. Readable Threats：玩家必须看懂为什么漏怪。
2. Meaningful Trade-offs：每次花费都有机会成本。
3. Wave as Teaching：波次用于教学与考核，不是线性抬数值。
4. Fast Iteration：失败后可快速重开验证新策略。

### 3.3 反支柱（Anti-Pillars）
1. 不做纯挂机型自动过关。
2. 不做外观不同但机制同质的“伪多样”。
3. 不做依赖隐藏规则制造挫败。

## 3.5 世界观核心设定（摘要）
在资源枯竭的荒原时代，人类依靠“余烬铁道”运输能量核心维持城市运转。  
未知异种会沿铁道节点成群侵袭，切断补给后城市将在数日内失温停摆。玩家扮演线路防卫指挥官，调度工程塔群守住关键枢纽。

## 4. 核心玩法设计
### 4.1 核心循环
1. 观察波次威胁结构。
2. 建造或升级塔。
3. 结算战斗结果与资源状态。
4. 根据失败/险胜信号调整阵型。

### 4.2 时间尺度循环
- 30 秒循环：放塔/开火/击杀反馈。
- 5 分钟循环：2-3 波后调整整体布局。
- 单局循环：从开局到失败/通关的一次构筑尝试。
- 长线循环：解锁塔与词条，扩大战术空间（Full Vision）。

### 4.3 胜负条件
- 失败：生命值归零。
- 胜利（MVP）：通过 20 波并完成结算。

### 4.4 单局流程（Battle Flow）
1. **战前准备（Prep）**：查看下一波威胁标签，分配预算。
2. **建造决策（Build）**：放置新塔或升级现有塔。
3. **战斗执行（Combat）**：敌人推进，塔自动索敌与开火。
4. **结果结算（Resolve）**：统计击杀、漏怪、预算变化。
5. **复盘调整（Adapt）**：根据失败标签调整覆盖、克制与经济策略。

### 4.5 决策层级（玩家在每波要做什么）
1. **战术层（3~10秒）**：当前波是否需要补“应急塔位”。
2. **结构层（30~90秒）**：阵型是否形成单体线 + 范围区 + 控制区。
3. **经济层（跨波）**：本波是“保守存钱”还是“强行投资过关”。
4. **反制层（章节）**：敌人抗性变化时是否切换主力塔组合。

### 4.6 失败反馈闭环（Readable Failure）
漏怪后系统输出不超过 3 条主因：
1. **输出不足**：单体伤害不够，重装单位漏防。
2. **覆盖断层**：高速单位穿越火力空区。
3. **克制错误**：对减伤/群体敌使用了错误塔组。

### 4.7 MVP核心体验目标（量化）
1. 前 5 波让玩家明确识别 3 类塔定位。
2. 第 10 波前让玩家至少做过 1 次“拆旧塔/改阵型”决策。
3. 第 15 波后不能靠单塔无脑堆叠稳定过关。
4. 每次失败后，玩家能在 30 秒内说出下一局调整动作。

## 6. 战斗系统企划（统一规范）
### 6.1 塔定位（首发 3 类）
1. 轨道长枪塔（单体）：高单点，处理高威胁目标。
2. 煤爆迫击塔（范围）：中低单点，高群体清杂效率。
3. 冷凝线圈塔（控制）：低伤，提供减速与节奏控制。

### 6.2 敌人定位（首发 4 类）
1. 掠行虫（低血高速）：测试覆盖与反应速度。
2. 甲壳重兽（高血低速）：测试单体持续输出。
3. 灰潮虫群（低血群体）：测试AOE与弹幕利用率。
4. 护甲孢体（减伤单位）：测试反制链与塔组合。

### 6.3 目标选择协议
1. 默认最近目标。
2. 锁敌窗口 `0.2s`。
3. 切换阈值 `new_distance < current_distance * 0.8`。
4. 目标失效即时重选，不加额外冷却。

### 6.4 关键公式
- 单体伤害：`final_damage = max(1, floor((tower_damage * damage_multiplier) - enemy_armor_flat))`
- 单体效率：`theoretical_dps = final_damage * attack_speed`
- AOE伤害：`aoe_damage = max(1, floor(final_damage * falloff_multiplier(distance_ratio)))`
- 经济效率：`gold_efficiency = effective_dps / tower_cost`

### 6.7 克制矩阵（首版）

|---|---|---|---|---|

| 煤爆迫击塔 | 中 | 低 | **高** | 中 |
| 冷凝线圈塔 | **高（控速）** | 中 | 高（控群） | 中 |

### 6.8 伤害结算流水线（Damage Pipeline）
1. 目标选择（锁敌协议）。
2. 命中判定（本项目默认必中，后续可扩闪避）。
3. 基础伤害计算（塔伤 * 倍率）。
4. 减伤结算（固定护甲）。
5. 状态效果附加（减速/灼烧等）。
6. 死亡与赏金结算（同帧只结算一次）。

### 6.9 战斗节奏约束（防止失控）
1. 同屏敌人建议上限：80（MVP）。
2. 单塔攻速硬上限：10/s。
3. AOE单次命中上限：12。
4. 若单波平均战斗时长 > 90s，则进入“拖时告警”并调低血量预算。

### 6.10 战斗系统实现优先级
1. 先做“参数可调 + 三塔四敌成立”。
2. 再做“克制矩阵与波次联动”。
3. 最后做“高级效果（穿透/连锁/暴击等）”。

## 7. 波次语法企划
### 7.1 波次结构原则
1. 每波一个主教学目标。
2. 三波节奏：`Introduce -> Reinforce -> Exam`。
3. 新机制首次出现时降低其他变量复杂度。

### 7.2 压力模型
- 波次预算：`wave_budget = base_budget + wave_index * growth_linear + growth_curve(wave_index)`
- 压力分数：`pressure_score = (incoming_hp_per_second * speed_factor) / expected_player_dps`

### 7.3 20 波教学蓝图（首版）
| Wave 区间 | 目标 | 主要压力 | 预期玩家学习 |
|---|---|---|---|
| 1-3 | 基础布防 | 低速低血 | 认识塔职责 |
| 4-6 | 覆盖缺口 | 高速小怪 | 处理漏怪路径 |
| 7-9 | 单体考核 | 高血单位 | 组合单体输出 |
| 10 | 小考试波 | 混合编队 | 快速重构阵型 |
| 11-14 | 经济拉扯 | 预算抬升 | 资源取舍 |
| 15-17 | 反制考核 | 抗性单位 | 反制链构筑 |
| 18-19 | 高压混编 | 群体+高血 | 全局协同 |
| 20 | 终局考试 | 综合波次 | 完整策略验证 |

## 8. 经济与成长企划
### 8.1 局内经济
1. 击杀收益是主要金币来源。
2. 波次结算给固定奖励，保障调整窗口。
3. 经济目标是“紧但可逆”，避免锁死局面。

### 8.2 升级策略（Vertical Slice）
1. 每塔 2 条小分支（伤害向 / 功能向）。
2. 单次升级必须改变手感或战术用途。
3. 3 次以上连续同塔升级会触发机会成本上升。

### 8.3 局外成长（Full Vision）
1. 新塔解锁。
2. 被动词条槽位。
3. 难度修正器与挑战模式。

## 9. 美术与音频企划
### 9.1 视觉方向
- 风格：Stylized 2D，清晰轮廓，高对比可读性。
- 目标：战场信息优先，装饰不抢读图。
- 配色：敌我明确分离，威胁级别有颜色层级。

### 9.2 image2.0（gpt-image-1.5）生产策略
1. 使用统一 prompt 模板与命名规范。
2. 首批资产：地块、路径、建造标记、基础塔、基础敌、投射物。
3. 每批资产先做 6 张小集评审，再扩批。
4. 生成脚本固定落地到 `Assets/Resources/Art/`。

### 9.3 音频方向（Vertical Slice）
1. 命中反馈分层（发射、命中、死亡）。
2. 高压波预警音。
3. 低生命值状态提示音。

## 14. KPI 与验收标准
### 14.1 玩法指标（内部）
1. Wave 1-5 新手通过率 >= 70%
2. Wave 10 通过率 40%~60%
3. Wave 20 首通率 10%~25%
4. 单塔伤害占比不长期超过总伤害 60%

### 14.2 体验指标（测试）
1. 玩家能在 10 分钟内解释三塔定位。
2. 失败后 80% 以上玩家能指出至少一个可改策略。
3. 重开到下一局的等待时间 <= 10 秒。

### 14.3 技术指标
1. 中配机器稳定 60 FPS。
2. 连续 30 分钟测试无严重内存增长。
3. 无 S1/S2 级阻断 Bug。
