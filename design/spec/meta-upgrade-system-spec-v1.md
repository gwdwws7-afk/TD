# 局外升级系统立项规格 v1（Meta Upgrade System）

> 来源：v9 任务 1（总导演已批准立项，插队 P0）。触发：世界地图 v2 重做暴露系统缺口，美术已备入口/面板资产（`campaign-worldmap-art-spec-v2.md`，`meta_entry_button` / `meta_panel_frame`）。
> 性质：**重复可玩性层**，不是战力层。四道护栏 = 本规格验收线。

---

## 护栏 1：MVP 克制（升级树只做 4 条线 × 10 个节点）

| 线 | 方向 | 节点（满级合成效应） | 设计意图 |
|---|---|---|---|
| A 后勤储备 | 起始资源 | 起始预算 +4 / +4（合计 +8，固定值） | 固定加值随关卡开销递增自然稀释——L01 约占起始预算 6%，L20 <3% |
| B 战地回收 | 局内经济·重构 | 拆塔返还 60% → 64% → 68% | 与拆塔系统（a57824f）协同，降低试错痛感，不改战斗数值 |
| C 清波津贴 | 局内经济·收入 | 清波收入 +2% → +2%（合计 +4%） | 挂在 p12.5.0 清波衰减曲线的**尾值**（70%）上，实际 +2.8pp |
| D 编队预案 | 重复可玩性·QoL | 编队预设位 +1 → +2（共 3 套） | 纯存档 QoL，零战斗威力——**明确不做第 5 编队槽**（编队宽度是威力门槛，见护栏 4 禁区） |

不做：全树铺开、塔/敌数值节点、专精/大招强化节点、任何战斗内词条。首版 10 节点封顶。

## 护栏 2：货币来源——余烬残渣（Ember Residue），明确新增

**获取回路（仅结算时入账，战斗内零存在）**：

```
单局残渣 = ⌊星级 × 难度系数 × 复取系数⌋
  难度系数：standard 1.0 / veteran 1.5 / ember_trial 2.2
  复取系数：该关该难度首取 1.0；复取 0.2（防同关刷取）
  失败局：⌊到达波数 / 20 × 正常值 × 0.15⌋（进度安抚，非奖励）
单局上限：60（含失败局）；同一存档槽内累计
```

节点定价：A/B/C 每级 40/90/160，D 每级 120——**全树毕业 ≈ 1000 残渣 ≈ 25-35 局有效游玩**（按主线三星首取 ~420 + 复取/难度补足估算）。

**与既有经济文档的关系（对齐声明）**：
- **明确新增**：P10.1 曾约束"不加新货币"（`p10-campaign-meta-loop.md:5`）——该约束的时点是战役内闭环；本系统是**战役后**层，本规格正式取代该行。P10.1 的"Standard 仍是 authored combat baseline"保留且被护栏 4 强化。
- **与 p12.5.0 对齐**：残渣在胜负结算**之后**入账，不进 `_defenseBudget`，不触碰 ending budget / final-five 决策价值判据（"终局结余 ≤999"等门禁口径不变）。

## 护栏 3：存档扩展（衔接 TDCampaignProgression）

槽级新增三个字段（沿用现有 `[Serializable]` 槽结构 + `towerLoadout` 式朴素序列化风格）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `emberResidue` | int | 当前余额 |
| `metaUpgradeRanks` | string | `"a1:2,b1:1,..."`（未购买项缺省，解析容错与 loadout 同标准） |
| `metaResidueLifetime` | int | 累计获取（防篡改对账：残渣增量之和 ≤ lifetime，超出即按既有防篡改策略回退） |

- 存档 `schemaVersion` +1，迁移器默认新字段全零（旧档 = 天然 meta-0，无迁移损失）
- 校验和覆盖新字段（防改存档刷残渣，与既有"防外部改存档抬升解锁"同链）
- 3 存档槽各自独立（与现有槽隔离一致）

## 护栏 4：平衡红线（必写，不可让步）

1. **meta-0 基线即发布基线**：全部现有矩阵（RailLancer 回归 25 局门禁、p135 体验门）继续以零元升级运行——**L01-L20 难度档位在 meta-0 下必须自洽**。刚为 L13/L20 付了两轮平衡代价，此条不因本系统让步。
2. **效果上限表（"爽感不是门槛"的量化）**：满级合成 = 起始预算 +8（L01 ≈ +6%，L20 < +3%）+ 清波 +2.8pp（尾值口径）+ 回收 68% + 编队 QoL。**验收判据：meta-0 与 meta-max 双档抽样矩阵（≥5 关 × 3 策略）胜率差 ≤ 2pp**——超出即砍节点数值，不放宽判据。
3. **禁区清单**：不改塔/敌任何数值；不加第 5 编队槽；不在战斗内产生/消耗残渣；不动难度倍率与章节奖励（Chapter 通关奖励与 A 线叠加后总量仍受上限表约束）；不与共鸣/场景指令耦合。
4. **QA 判据扩展**：帽后矩阵判据树（v7-v9）原样适用于 meta-0；meta-max 抽样矩阵为新增独立门。

## 入口交互流（与美术已备资产对齐）

```
世界地图（右下，DEPLOY 侧）
  └─ [meta_entry_button 384²，锻铁+琥珀徽记]（余额角标：残渣数）
        └─ 点击 → [meta_panel_frame 1536×1024 九宫格] 面板
              ├─ 顶部：残渣计数 + 生涯获取
              ├─ 中部：4 条升级线（A-D）× 节点位（已购=琥珀点亮/可购=呼吸高亮/不足=灰）
              │    └─ 点击可购节点 → 扣残渣 → 节点点亮动画 + 计数滚动（即时生效，无需重启局）
              └─ 底部：关闭（返回世界地图；编队预设线购入后编队面板出现预设切换页签）
```

- 面板打开时世界地图降暗暂停（与任务板同层级模态）
- 所有反馈文案双语（en/zh，走 strings.json 新键，不留硬编码）
