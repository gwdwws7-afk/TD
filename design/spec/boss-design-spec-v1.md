# Boss 设计规格 v1（四考试关 Boss）

> 来源：content-expansion-master-spec-v1 派生。四名新 Boss 的相位/技能/反制完整规格——行为代码与美术（10-12 帧 + 相位 FX）的输入。
> 共同规则（见 content-matrix v2 §5）：免疫 stagger/击退；可标记/暴露/破甲；Boss 警告 FX；W20 `boss_entry` 插入。
> 难度基准：standard 口径数值，veteran/ember 沿用战役倍率（×1.15/×1.3）。

---

## 1. 集装箱装卸兽 Containermaw（L05 · 首个 Boss）

**身份**：玩家遇到的第一个 Boss——教学"Boss 是可以读的"。
**基线**：HP 320｜甲 10｜速 0.5｜lineDamage 3｜threatCost 14

| 相位 | 触发 | 行为 |
|---|---|---|
| 一段·重装段 | 100%→50% | 甲 10、速 0.5；**每 12s 抛起集装箱**：随机封锁一个授权建造格 10s（视觉：箱体砸落 + 尘土；被封锁格不可建造/升级） |
| 二段·卸甲狂奔 | <50% | **卸甲**（10→2）、速 ×1.6（0.8）、lineDamage 3→5；停止抛箱 |

**反制教学**：一段考验反甲（钻机/信标标记集火），二段考验控速（线圈/陷阱）——正好是 L01-L05 已学的两套答案。封锁建造格 = "储备窗口"考试身份的空间经济版。
**相位提示**：50% 触发卸甲 FX（甲片崩落 6 帧）+ 低频轰鸣。

## 2. 岔道暴君 Junction Tyrant（L09 · 道岔考试）

**身份**：多线图的移动威胁——"改道"从场景技升级为对手行为。
**基线**：HP 380｜甲 6｜速 0.7｜lineDamage 4｜threatCost 15

| 相位 | 触发 | 行为 |
|---|---|---|
| 一段·改道段 | 100%→35% | **每 15s 强制自身改道**（从当前线切换到另一条线的等价进度点）；玩家可用 Route Switch 场景技反制（抢先改回或预布双线） |
| 二段·分裂段 | <35% | **分裂为双体**：各 50% 当前 HP、甲 4、速 0.85，分走两条线同时推进；双体共享 Boss 警示 FX |

**反制教学**：一段考验预判布防（双线覆盖），二段考验火力分配——"道岔承诺"考试的终极形态。分裂瞬间清空双体身上的标记/暴露（防止白嫖）。

## 3. 窑炉看守 Kiln Custodian（L13 · 窑压考试）

**身份**：反甲机制的活体考题——叠甲与场景技的直接对决。
**基线**：HP 420｜甲 6（基础）｜速 0.6｜lineDamage 4｜threatCost 16

| 机制 | 规则 |
|---|---|
| **随时间叠甲** | 每 10s 甲 +1，上限 +8（最高 14）；UI 甲条随动 |
| **相位召唤** | 70% 与 35% 触发：召唤窑潮（6 灰烬虫群 + 2 覆甲孢子）从后方刷入 |
| **场景技交互** | Kiln Purge 命中看守时：甲 -5 且**暂停叠甲 8s**——唯一压制手段 |

**反制教学**：这是"护甲帽"平衡哲学的 Boss 化——无解的甲墙不存在，但答案只有一个（窑压时机）。考试身份"打断最密虫群并保留出口控制"完整继承：召唤波与 Purge 冷却形成时序谜题。
**实现注记**：叠甲状态复用现有 armorBreak 的反向槽（负破甲），不新增字段。

## 4. 回响先驱 Echo Harbinger（L17 · 相位考试）

**身份**：拟态主题的 Boss 化——它用你自己最强的东西对付你。
**基线**：HP 460｜甲 8｜速 0.65｜lineDamage 5｜threatCost 16

| 机制 | 规则 |
|---|---|
| **拟态** | 战斗开始时读取玩家本场**建造数量最多的塔种**，获得其简化行为（见下表） |
| **相位重拟态** | 70% 与 35%：清空自身所有 debuff（标记/暴露/破甲），改拟态**第二多**的塔种（35% 改第三多） |

**拟态行为表**（简化版，均每 6s 一拍）：

| 拟态塔种 | 先驱获得 |
|---|---|
| 长枪/轨道炮类 | 突进：自身速 ×1.8 持续 2s |
| 迫击/喷灯类 | 灼烧冲击：1.5 格内塔攻速 -12% ×4s |
| 线圈/陷阱类 | 相位润滑：自身免疫减速 5s |
| 钻机类 | 重锻：自身甲 +3（可叠，Purge/破甲可削） |
| 高炮/焊机类 | 弹幕护体：接下来 3 次命中伤害 -50% |
| 信标/吊机/轨障类 | 信号干扰：暂停玩家共振充能 3s |

**反制教学**：揭穿它 = "相位准备"考试身份——在 70/35 阈值前挂满 debuff 的时机决策（早挂会被清，晚挂浪费窗口）；多塔种混编降低被拟态强度。
**实现注记**：读取本场建造统计（`_towerStats` 现成）；拟态行为全部为自体 buff，不新增敌人攻击塔的路径（酸蚀孢囊的死亡溅酸仍是唯一塔 debobuff 敌）。
