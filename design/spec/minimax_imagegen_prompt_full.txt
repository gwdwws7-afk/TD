我要为一个 2D 塔防游戏《Emberline Defense》(余烬铁道)批量生成游戏美术图片。请你先通读下面的世界观、视觉调色板和技术约束,然后按 P0 → P1 → P2 的顺序逐个生成图片文件。每生成一张,严格用对应的文件名命名。

# 一、世界观(所有图片必须服从)

人类文明的余烬铁道在衰败。玩家是最后一位线务司令,在锈蚀的铁轨、冷却的熔炉、崩塌的终点站之间,用工业化战争机器抵御从灰烬中涌出的变异生物。视觉基调是"温暖的衰败"——夕阳下老机器还在轰鸣的忧郁工业浪漫。

视觉参考坐标:现有资产库(塔=机械构造+能量核心+宝石徽章图标语言;地图=5 张手绘地表:冷灰编组站/灰烬荒漠/赭石裂谷/暗红窑炉盆地/近黑终点站)。

# 二、视觉调色板(每张图都要落在这 6 类里)

1. 金属呼吸:锻铁、铆钉、做旧钢板、锈蚀流痕 → 塔身、机械、UI 框架
2. 余烬纹理:琥珀橙色发光、火舌、煤渣、暖色体积光 → 能量核心、发光标识
3. 机械结构:齿轮、连杆、液压撑脚、铁轨枕木 → 结构细节与升级模块
4. 生物质感:甲壳、湿滑有机形态、低饱和暗色皮膜(有机但不恶心) → 敌人
5. 空间氛围:暗角、远处暖光源、薄雾、手绘笔触 → 背景与氛围层
6. 点缀色:青色/蓝紫/绿色按身份色少量出现(各塔/各区身份识别)

# 三、全局技术约束(每张图必须满足)

- 尺寸:1024×1024(方形资产)或 1536×1024(横幅资产);世界图任意 16:9 横图
- 格式:PNG;除 world_map_bg(不透明)外全部透明背景
- 单主体居中,占画布 60-80%,边缘干净无残留底、无灰雾薄膜、无棋盘格
- 手绘数字绘画质感(hand-painted),与上述参考坐标同语言
- 严禁:文字、水印、UI 框、额外背景场景、拍照感、3D 渲染感

# 四、参考图规则(img2img 类资产)

- P0-A 的 4 张 T2 帧:每张必须上传对应底图(见各条目),保持塔身姿态像素级一致,只叠加升级模块
