# 轨障车行为规格 v1（Rail Barricade Blocker System）

> 来源：expansion-tower-sheets-v1 塔 11 的工程派生。拦截品类需要的敌人 AI 扩展完整规则——代码会话实现的契约文档。
> 原则：拦截买时间，不买无敌——每条规则都为"可被反制"设计。

## 1. 拦截实体（Blocker Wagon）

- 轨障车塔放置于授权格且**邻接路段**时，在最近路段点生成拦截车体（独立实体，非塔本体）
- 车体属性随塔升级（见塔 11 数值表：HP 240/甲 4 起）；每路段**至多一个**车体
- 车体不可被玩家选中/出售（出售塔 = 撤收车体，即时消失）

## 2. 敌人接战规则

| 规则 | 内容 |
|---|---|
| 阻挡 | 敌人行进路径穿过车体所在路段点时**停下**，进入接战 |
| 接战容量 | 单车体同时接战 ≤2 名敌人（前排）；其余敌人**排队等待**（不绕行——路径是唯一的） |
| 接战攻击 | 接战者每 1.2s 对车体造成 `lineDamage` 点伤害（复用漏防伤害作攻击力——威胁越大的敌拆得越快） |
| 通行 | 车体被毁 → 全部等待者恢复行进；25s 自动重建（Holding Order 15s） |

**绕行者（明确清单，反制平衡）**：
- 掘地工兵：潜行无视车体（它本来就走地下）
- 烬火滑翔者：飞越车体（flank 身份）
- **全部 Boss**：碾压——一击摧毁车体并停顿 3s（Boss 永不被硬停，但碾压窗口 = 玩家爆发窗口）
- 灰烬虫群：数量 >4 时多余个体从车体缝隙渗过（每 4 只漏 1——虫群不怕路障的题材理由）

其余敌人（含回声拟态体/回响虫群/锻炉骑兵/酸蚀孢囊等）全部正常接战。

## 3. 数值框架

- 车体 HP 240 ≈ 裸接战标准敌人（lineDamage 1-2）×120-240s ≈ 2-4 波有效拖延；重威胁（4-5）约 60-90s
- 荆棘反伤不吃护甲减免（固定伤）——对 Shield 类（锻炉骑兵前 3 次免疫）无效（保持克制关系）
- 车体不计入塔 DPS 统计（零贡献口径豁免——避免拆塔 AI 误卖轨障）

## 4. 系统交互核对

| 系统 | 交互 |
|---|---|
| 共振 | 车体受击不产生充能（它不是塔攻击）；裂痕标记不作用于接战（敌人已停）——拦截与共振零耦合（红线保持） |
| 场景技 | Signal Gate 减速与车体排队叠加正常；Kiln Purge 等范围技照常命中接战者 |
| 拆塔/出售 | 出售轨障塔撤收车体；autoplay 出售判据：车体当前接战数 = 0 才可卖（防自拆防线） |
| 波次判定 | 接战中敌人不计入"波已清空"判定——漏怪计时与车体共存亡 |
| 存档 | 车体状态不存档（波间重建为满血——简化且符合"建造窗口重置"惯例） |

## 5. 实现注记（代码会话）

- 敌人状态机新增 `Engaged` 态（停止 + 攻击计时器），迁移：`Moving ↔ Engaged`（车体毁/敌死）
- 寻路不改动（路径不变，接战是位置锁定而非改道）
- 预估 ~300-400 行（含 FX/UI 接战提示）——主规格估的 3-5 天成立
- 单测建议：接战容量、绕行者清单、Boss 碾压、波清空判定、autoplay 出售守卫五项
