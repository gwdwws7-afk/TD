# 一、世界观(所有图必须服从)

人类文明的余烬铁道在衰败。玩家是最后一位线务司令。关卡选择界面是一张手绘的战役世界地图:五个自然地貌区沿一条主铁路蜿蜒铺开,20 个关卡各自锚定在自己的地貌区里,每个关卡有专属地标构筑物、状态徽章和三枚难度印章,右下角有局外升级入口。视觉基调"温暖的衰败"——夕阳下老机器还在轰鸣的忧郁工业浪漫。

五个地貌区(自上而下旅程顺序)与调色板:
- 灰线编组平原(L1-L4,冷灰钢构+青色信号灯):cold-grey weathered steel, slate concrete, thin teal signal lights
- 灰烬仓库区(L5-L8,暖灰+漂浮余烬+锈橙塔吊):warm ash-greys, drifting ember motes, rust-orange cranes
- 裂谷道岔区(L9-L12,赭石红岩层+暗色木栈桥):ochre and rust-red rock strata, dark timber trestles
- 窑炉盆地区(L13-L16,火山玄武岩+窑红熔渣):dark volcanic basalt, glowing kiln-red slag, soot-stained iron
- 最后余烬终点站(L17-L20,近黑废墟+一盏暖琥珀信号灯):near-black derelict structures, one warm amber signal glow

# 二、全局技术约束

- 手绘数字绘画质感(hand-painted),与上述五区调色板同语言
- 透明背景 PNG(仅 world_map_bg 不透明),单主体居中占画布 60-80%
- 边缘干净:严禁残留底、灰雾薄膜、棋盘格(之前批次踩过的坑,硬性红线)
- 严禁文字、水印、UI 外框、多余场景、3D 渲染感

# 七、产出落地与导入

原图统一放 output/imagegen/_worldmap_raw/(按上面各文件名),然后在仓库根目录:
```bash
python tools/generate_worldmap.py --wave 1 --import-only   # 先导世界图
python tools/generate_worldmap.py --wave 2 --import-only   # 验收通过后导其余 33 张
# 单张重导示例
python tools/generate_worldmap.py --only landmark_L07 node_boss --import-only
```
导入命令自动完成:抠透明背景 → 按目标尺寸/形态后处理(世界图 16:9 裁切放大、宽幅铭牌内容裁切、小件降采样) → 落位 Assets/Resources/Art/UI/Campaign/。
