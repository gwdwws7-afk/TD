## 一、四座新塔（每塔 24 帧 + 弹/效/UI 各 1）

### 塔 9 · 炉渣喷灯 slag_burner（L04｜持续伤害｜身份色 熔渣红 #D64545）
- **剪影**：低趴轨行熔炉车，前伸喷灯长矛（斜上 30°），炉体背鼓包、烟囱后掠；
  火焰始终半燃（pilot light）
- **T2 模块**：双喷口 + 炉侧 slag 槽（熔渣红发光液位窗）
- **T3 模块**：炉体膨胀成移动熔窑，喷灯变三联转管，地面积渣光环
- **弹**：`projectile_slag_burner` 扁平熔渣火舌；**效**：`impact_slag_burner` 溅渣灼坑

### 塔 10 · 捞轨吊机 salvage_derrick（L09｜经济工具｜身份色 打捞绿 #7FC86E）
- **剪影**：轨行桁架吊机，磁吸抓斗前伸，配重块后坐；抓斗缆绳常驻微摆
- **T2 模块**：副臂 + 分类料斗（绿光分拣窗）
- **T3 模块**：双臂龙门化，顶部打捞信标灯球（绿光呼吸）
- **弹**：钩爪射弹；**效**：赏金吸附涡（金币向内流）

### 塔 11 · 轨障车 rail_barricade（L14｜拦截｜身份色 警戒钢蓝 #5D8AA8 + 黄黑警示条）
- **剪影**：贴轨装甲车，犁头排障铲前伸，车顶探照灯；车体警示斜纹
- **T2 模块**：侧展翼闸 + 缓冲蜂窝层
- **T3 模块**：全宽路障形态（双车并联铆接），殉爆预热管（暗红待机光）
- **弹**：无弹道（近身碰撞）；**效**：`impact_rail_barricade` 冲撞尘暴

### 塔 12 · 远程轨道炮 long_rail_cannon（L18｜超远程穿透｜身份色 深空紫 #6C5CE7）
- **剪影**：加长双层轨道炮（rail_lancer 的重型兄长），多级加速环，尾部
  接地桩缆；炮身上仰 15°
- **T2 模块**：加速环 ×2 + 装填弹匣鼓
- **T3 模块**：轨道延至画布边（视觉即"全场射程"），紫电弧常驻缠绕
- **弹**：贯穿紫色等离子长钉；**效**：线穿透蓝紫电离尾迹

**帧数**：每塔 idle 6 + t2 idle 6 + t3 idle 6 + fire 3 + t3_fire 3 = **24 帧**
（t2_fire 缺省回退基础 fire，与现有 8 塔一致）。计 **96 帧 + 弹 4 + 效 4 + UI 徽章 4 = 108 件**。

### §二补（v1.1，2026-08-27）：六新敌身份锚定与行为可读性契约——C-2 小样验收依据

**现有 12 敌色彩普查**（饱和不透明像素 hue 分布）：余烬红带 0-30° 为家族主带（furnace_matriarch 99% / husk_titan 93% / carapace_brute 91% / rail_warden 88% / burrow_sapper 68%）；绿带 60-120° = 生物系（spore_carrier 65% / plated_spore 35%）；蓝紫带 240-270° = echo 系（echo_mimic 68%）；琥珀带 30-60° = cinder_glider / skitter_runner。

**敌方色彩政策与塔相反**：塔要 12 色互斥可读；敌是"余烬衰减世界"的同一阵营——**家族带优先，威胁类型靠剪影第一、行为 FX 第二、hue 第三**。六新敌锚定（小样必须逐敌过验）：

| 敌 | 家族带 / 身份色 | 与现有敌的区隔 | 行为可读性契约（预状态 → 触发 → 死亡） |
|---|---|---|---|
| cinder_husk | 余烬红带：炭黑体 + 关节裂纹亮橙 #E8842A | vs husk_titan：人形 vs 巨型（高度差 ≥1:2）；vs ember_leech：直立拖行 vs 匍匐 | 蓄势：无（普通敌）；死亡余烬堆必须读作**地面物**不读作敌——低矮无剪影 + 橙微光 + 8s 渐熄 |
| rail_splitter | 锈红节片 + 钢亮楔形头（节片反光拉开与路轨的对比） | 全场唯一扁平贴轨剪影。**禁纯钢蓝主体**——会沉进路轨灰蓝里（C-1 barricade 色相塌缩教训的敌方版） | 直道加速前摇：楔头下压 + 节片收紧（idle 后段 1-2 帧，可读"要窜了"）；加速拖影蓝白 #BFE8F5 |
| acid_blister | 亮黄绿 #C8E06A 半透明囊体，明度/饱和高于 spore 系叶绿 | vs spore_carrier/plated_spore 绿簇：半透明 + 内气泡质感；acid 与 spore 允许同族不同档（亮 vs 沉） | **喷酸蓄势**：囊体鼓胀 15-20% + 内气泡加速（可读"要炸"）；死亡酸雾圈是全场唯一大面积绿 FX（塔位减益的地标功能） |
| forge_dragoon | 双色功能契约：锻体余烬红 + 盾面冷钢蓝 #7FA8C4 | 第 4 个余烬红甲敌——区隔靠**暖体 + 冷盾**的功能色对读（现有敌无此双读） | 护盾层必须**可数**：3 层独立轮廓清晰分离；逐层崩解 3 段 FX；锻造红缝亮度随受击升高 |
| ember_strider | 炭黑低饱和高瘦剪影 + 足部/腿关节余烬亮橙 | vs husk_titan：瘦高 vs 巨壮（腿长占比 >50%）；标记敏感纹体表常驻暗态 | 被标记态：纹样全亮 + 红光描边（读作"打它更疼"）；余烬拖尾只在移动方向 |
| echo_brood | 蓝紫带承 echo_mimic（家族 240-270°） | vs echo_mimic：虫群聚合体 vs 单体拟态；**真体/残影以饱和度 + alpha 区分，不以 hue 区分** | 残影 = 40-50% alpha + 降饱和（禁全饱和残影）；死亡复制 FX：2-3 残影向散向分离 |

**三条通用红线（小样与全量同权）**：
1. 新敌主色避开纯琥珀大面（cinder_glider/burrow_sapper 已占用该带，第三方进入会塌缩敌方内部可读性）；
2. 行为可读性帧（喷酸蓄势 / 可数盾层 / 标记纹 / 残影区分 / 加速前摇）是**规格项**——每敌小样必须含 1 帧行为态；
3. 死亡产物（余烬堆/酸雾圈）必须用地面贴图语言与敌剪影系统区分。
