我要为一个 2D 塔防游戏《Emberline Defense》(余烬铁道)的"战前编队界面"生成一套调度仪表台控件皮肤(10 张卡/牌/横幅)。请你先通读世界观和技术约束,然后按清单顺序逐个生成,每张严格按对应文件名命名。注意:清单里有 4 张是"状态变体"——必须以上一张基础卡的产出作为参考图(img2img),保持构图、比例、槽位完全一致,只改变点亮状态。

# 一、世界观(所有图必须服从)

人类文明的余烬铁道在衰败。这个界面是"铁路调度仪表台":锻铁深炭色底、青色仪表光点缀、琥珀描边。所有卡片是仪表台的控件——嵌槽留白给代码叠加的图标与文字,卡上绝不 baked 任何文字或图标。与现有指挥框(frame_command,锻铁+青仪表光)同一语言。

# 二、全局技术约束

- 透明背景 PNG,横幅类按 3:2 横图出,情报卡按 2:3 竖图出
- 卡片为"底板":内容区(图标槽/文字槽)必须留白凹陷槽,不画内容
- 九宫格友好(四边可拉伸),边缘干净无残留底/灰雾(硬性红线)
- 手绘数字绘画质感,严禁文字、图标、水印、3D 渲染感

# 四、产出落地与导入

原图统一放 output/imagegen/_formation_raw/(按上面各文件名),然后在仓库根目录:
```bash
python tools/generate_formation.py --import-only   # 全部导入
python tools/generate_formation.py --only roster_card_selected --import-only  # 单张重导
```
导入命令自动完成抠透明背景、内容裁切、按目标尺寸落位 Assets/Resources/Art/UI/Formation/。

状态变体若手动生成:先做 base,把 base 原图上传给 AI 再生成变体,确保构图一致。
