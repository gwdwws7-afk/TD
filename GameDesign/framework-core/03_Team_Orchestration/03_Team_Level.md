# Team Level

Complete area/level creation with level-designer, narrative-director, world-builder, art-director, systems-designer, QA-tester.

## Roles

| Role | Responsibility |
|------|---------------|
| Level Designer | Layout, pacing, encounters, flow |
| Narrative Director | Story placement, lore discovery |
| World Builder | Environmental narrative, lore |
| Art Director | Visual style, asset requirements |
| Systems Designer | System integration points |
| QA Tester | Playtest level, find issues |

## Level Creation Pipeline

### 1. Level Concept
- Define level goals and theme
- Narrative purpose (story beat, exploration)
- Systems integration (what mechanics appear)
- Pacing structure (tension peaks and valleys)

### 2. Layout Design
- Blockout creation (basic shapes)
- Navigation and flow analysis
- Encounter placement
- Loot/discovery placement

### 3. Systems Integration
- Difficulty tuning for encounters
- Progression gating based on abilities
- Collectible/hidden content placement

### 4. Polish Pass
- Art director asset placement
- Environmental storytelling
- Lighting and atmosphere
- Audio ambience

### 5. Validation
- Playtest for pacing and difficulty
- Bug fixing via `/bug-report`
- Performance optimization

## Level Design Principles

- First and last 30 seconds: Memorable opening, clear objective
- Breadcrumbs: Guide without hand-holding
- Breathing rooms: Rest points between challenges
- Vertical space: Reward exploration
- Multiple paths: Player choice matters

## Output

Level designs saved to: `design/levels/[area-name]/`
