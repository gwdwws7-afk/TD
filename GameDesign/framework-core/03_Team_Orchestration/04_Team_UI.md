# Team UI

UI feature pipeline from wireframe to final with ux-designer, ui-programmer, art-director.

## Roles

| Role | Responsibility |
|------|---------------|
| UX Designer | User flows, information architecture |
| UI Programmer | UI implementation, systems integration |
| Art Director | Visual style, iconography, typography |

## UI Pipeline

### 1. UX Design
- Define user flows
- Create wireframes
- Information architecture
- Accessibility requirements

### 2. Technical Design
- UI system GDD via `/design-system ui`
- Data-driven UI architecture
- Localization requirements
- Platform-specific considerations

### 3. Visual Design
- Art director creates UI mockups
- Iconography and typography
- Color palette and style guide
- Animation and transition specs

### 4. Implementation
- UI programmer builds screens
- Integration with game systems
- Input handling (gamepad, mouse, touch)
- Localization string integration

### 5. Polish
- Animation and juice
- Sound feedback
- Loading states, error states
- Empty states

## UI Design Principles

- Clarity over cleverness: Player finds info instantly
- Consistency: Same patterns throughout
- Contextual: Right info at right time
- Accessible: Colorblind modes, scalable text
- Performant: Minimal draw calls, fast load

## Deliverables

| Phase | Deliverable |
|-------|-------------|
| UX | Wireframes, flows |
| Tech | UI GDD, data schema |
| Visual | Mockups, style guide |
| Implementation | All UI screens |
| Polish | Animations, feedback |
