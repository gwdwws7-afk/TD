# Team Narrative

Orchestrates narrative content pipeline with narrative-director, writer, world-builder, level-designer.

## Roles

| Role | Responsibility |
|------|---------------|
| Narrative Director | Story structure, tone, lore consistency |
| Writer | Dialogue, quest text, narrative content |
| World Builder | Lore, history, character backgrounds |
| Level Designer | Environmental storytelling, placement |

## Narrative Pipeline

### 1. Story Architecture
- Narrative director defines story structure
- Define act breaks, major beats
- Character arc definitions
- World lore bible created

### 2. System Integration
- Dialogue system design via `/design-system dialogue`
- Quest system design via `/design-system quests`
- Narrative GDDs cross-referenced with gameplay systems

### 3. Content Creation
- Writer creates dialogue trees
- World builder populates lore codex
- Level designer places narrative elements

### 4. Integration
- Dialogue connected to gameplay triggers
- Quests integrated with progression
- Environmental storytelling validated

### 5. Localization
- `/localize scan` for hardcoded text
- String extraction for translation
- RTL language support considered

## Narrative Design Principles

- Show don't tell: Environmental storytelling over exposition
- Player agency in narrative: Choices that matter
- Consistent tone: Every word reinforces the world
- Systemic narrative: World reacts to player actions

| Phase | Deliverable |
|-------|-------------|
| Architecture | Story structure, lore bible |
| Systems | Dialogue/quest GDDs |
| Content | All dialogue, quests, lore entries |
