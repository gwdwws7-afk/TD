# Launch Checklist

Complete launch readiness validation across all departments.

## Usage

```
/launch-checklist
/launch-checklist --env staging
```

## Categories

### Code
- [ ] All milestone criteria met
- [ ] No known S1/S2 bugs
- [ ] Performance benchmarks met
- [ ] Platform certification passed

### Content
- [ ] All promised features implemented
- [ ] No placeholder content
- [ ] Tutorial/tooltips complete
- [ ] Ending content complete
- [ ] All localizations ready

### Store
- [ ] Store pages submitted
- [ ] Screenshots/videos uploaded
- [ ] Age rating obtained
- [ ] Rating symbols correct

### Marketing
- [ ] Press kit ready
- [ ] Trailer published
- [ ] Social media plan active
- [ ] Influencer keys sent

### Community
- [ ] Support channels ready
- [ ] Community guidelines posted
- [ ] Discord/server configured
- [ ] FAQ prepared

### Infrastructure
- [ ] Servers deployed
- [ ] Monitoring configured
- [ ] Analytics events verified
- [ ] Crash reporting verified
- [ ] Rollback plan tested

### Legal
- [ ] Privacy policy live
- [ ] Terms of service accepted
- [ ] Copyright notices present
- [ ] Third-party credits complete

### Sign-offs
- [ ] Creative Director: [ ]
- [ ] Technical Director: [ ]
- [ ] Producer: [ ]
- [ ] QA Lead: [ ]
